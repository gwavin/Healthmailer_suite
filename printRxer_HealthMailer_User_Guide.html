printRxer / HealthMailer User Guide

A quick guide for staff using printRxer to prepare a prescription or clinical document for scheduled sending through HealthMailer.

AudienceEnd users
PurposeSelect recipient, review document, prepare sending
StatusControlled pilot / approved local use
Important: printRxer does not send the email itself. It prepares a checked handoff package. HealthMailer then sends the document through the approved local Outlook / Healthmail sender setup.

1. What this tool is for

printRxer is used when a prescription or clinical document needs to be sent securely to an approved pharmacy or clinician recipient. The tool lets you search for the correct recipient, review the document details, choose whether the item is a prescription or clinical document, and prepare it for scheduled sending.

The aim is to make the final check explicit: you can see the selected recipient, the attachment filename, the subject, and the message before the package is prepared.

2. Before you start

  • Check that you are working on the correct patient/document in the clinical system.
  • Print or send the document to the local printRxer printer when instructed by your local workflow.
  • Wait for the recipient picker window to open.
  • Do not use the tool if the picker shows unexpected patient/document details. Cancel and start again.
Patient-identifiable information: documents, attachment filenames, and audit evidence may contain patient identifiers such as MRN. Use the tool only for approved clinical communication workflows and follow local information governance procedures.

3. Basic workflow

1

Search and select

Search for the correct pharmacy or clinician. Select the intended recipient from the list.

2

Review details

Review document type, document name, attachment filename, subject, and message.

3

Prepare package

Select Prepare for scheduled sending. HealthMailer will handle the approved sending path.

4. The recipient picker screen

Recipient search

Use the search box to find the intended pharmacy or clinician. The recipient list may show names, email addresses, aliases, services, or other search terms. Select the correct row before preparing the document.

Safety check: the package cannot be prepared until a recipient has been explicitly selected. Do not rely on the first visible result unless you have selected and checked it.

Print job context

The picker may show contextual information such as patient, MRN/chart, prescriber, print time, job number, or Windows user. These are provided to help you check that the document is the one you intended to send.

FieldWhat to check
PatientCheck that the displayed patient hint, if available, matches the intended document.
MRN / chartCheck the identifier if shown. If unavailable, rely on the source document preview and local workflow checks.
PrintedCheck that the time is consistent with the document you just printed/prepared.
Job / userUseful for support/audit if something unexpected occurs.

5. Document type, name, and filename

The picker lets you choose whether the outgoing item is a Prescription / Rx or a Clinical document. This choice helps populate the suggested subject, message, and attachment filename.

Document typeTypical attachment filenameTypical message wording
Prescription / RxMRN123456_prescription_20260526_1430.pdfPlease see the attached prescription.
Clinical documentclinicalDocument_20260526_1430.pdfPlease see the attached clinical document.
Attachment filename: this is the filename the recipient will see in the email. The internal package file remains unchanged for validation.

You may edit the attachment filename before preparing the package. Keep it clear, short, and appropriate. Do not add extra patient identifiers unless required by the approved workflow.

6. Subject and message

Review the subject and message before preparing the package. The suggested wording is intentionally brief and neutral.

Subject: Prescription

Hello,

Please see the attached prescription.

Clinical document example

Subject: Clinical document

Document: Clinical document

7. Previewing the document

Use Preview document if you need to check the attached PDF before preparing it. If the preview does not open, cancel and contact local support if the problem persists.

8. Preparing for scheduled sending

When you are satisfied that the recipient, document type, filename, subject, and message are correct, select:

Prepare for scheduled sending

This creates the HealthMailer handoff package. The picker then closes. Depending on the local setup, HealthMailer will process the package through the approved sending workstation/user profile.

9. Privacy timeout and cancellation

The picker closes automatically after 3 minutes for privacy. If it closes before you finish, start again from the original workflow.

Selecting Cancel closes the picker without preparing a package.

10. When to stop and ask for help

  • The patient or MRN shown does not match the intended document.
  • The recipient list does not contain the expected recipient.
  • The recipient email address looks wrong.
  • The attachment filename, subject, or message cannot be corrected.
  • The preview opens the wrong document.
  • The tool shows an error, closes unexpectedly, or repeatedly fails to prepare the package.
